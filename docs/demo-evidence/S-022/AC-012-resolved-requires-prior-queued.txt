WHAT THIS DEMONSTRATES:
  An observer receives two sequential messages and the test asserts: (1) the first message
  is PermissionPromptQueued for the expected prompt_id, and (2) the second message is
  PermissionPromptResolved for the same prompt_id. This confirms message ordering and that
  Resolved cannot precede Queued. The broader structural invariant is enforced at the
  registry level: PermissionPromptResolved is only produced by resolve_prompt() or
  remove_timed_out_prompt(), both of which require a prior register_prompt() call for the
  same prompt_id — no orphan Resolved messages are architecturally possible.
