WHAT THIS DEMONSTRATES:
  After the client receives its InitialState message, the test injects a
  DropCounterUpdate(99) directly into the subscriber list — simulating a daemon push
  that does not result from any client request. The client receives this push as its
  second message without having sent any intervening bytes. The client never calls a
  "poll" request; all state changes arrive via server-initiated push over the open
  UnixStream, confirming the push-only model.
